# IEEE Menoufia Student Branch Portal — V1 Scope

## 1) What is the Portal?
The portal is the official digital platform for IEEE Menoufia SB to:
- Publish public information (committees, events, gallery)
- Manage internal operations (members, volunteers, tasks, HR recruitment)
- Run event operations (registration, attendance check-in, reporting)
- Centralize announcements and communications

---

## 2) Target Users
- Visitors (public)
- Members & Volunteers
- Committee Leads
- Branch Officers (ExCom)
- Event Organizers & Scanners

---

## 3) V1 Core Features (Deliverables)

### 3.1 Public Website (Official Presence)
- Home page (highlights, upcoming events, CTAs)
- About page (branch mission + overview)
- Committees section (RAS, AI, Web, Cyber, HR, PR, Media)
  - Each committee has a public page (mission, activities, join CTA)
- Events section (upcoming + past events, event details pages)
- Gallery (albums for key events)
- Contact section (official links & communication channels)

### 3.2 Authentication & Role-Based Access
- Secure login for members and staff
- Multi-role support (a user can hold more than one role)
- Role-based access control to protect internal dashboards and sensitive actions

### 3.3 Member Portal (Internal Area)
- Personal dashboard:
  - My committees
  - My tasks
  - My events (registrations)
- Profile page (basic information + committee membership)

### 3.4 Committee Workspaces (Internal Operations)
For each committee:
- Workspace page (visible only to assigned members)
- Members list (committee visibility)
- Task management:
  - leads assign tasks
  - members update task status
- Resources section (links/documents for onboarding & work)
- Internal announcements

### 3.5 Event Operations (Registration + Attendance)
- Public event pages with registration entry point
- Integration with event registration system (where available)
- Event organizers dashboard:
  - attendee list view
  - export list (CSV)
  - basic attendance reporting
- Event scanner mode:
  - QR check-in for attendance (for authorized scanners only)

### 3.6 HR Recruitment & Onboarding (Volunteer Pipeline)
- Recruitment campaigns (open/close)
- Applications collection
- Review pipeline (stage tracking)
- Acceptance/rejection decisions
- Onboarding checklist for accepted volunteers

### 3.7 PR / Media Operations (Basics)
- Announcements module (internal announcements + optional public announcements)
- Gallery album management:
  - create albums
  - upload media
  - publish albums to public gallery (via publisher approval)

### 3.8 Governance & Transparency (Admin Controls)
- Role assignment management (admin/officers)
- Audit logs for sensitive actions (publishing, role changes, exports, HR decisions)

## 4) V1 Committees Supported
- RAS
- AI
- Web
- Cyber
- HR

Each committee will have:
- Public identity page
- Internal workspace and task tracking
- Membership and internal announcements

## 5) Out of Scope for V1 (Not included)
- Full sponsor/CRM management system
- Complex finance/inventory modules (beyond basic needs)
- Advanced analytics dashboards
- Full in-portal chat (if not needed immediately)
- AI-driven automation features (recommendations, summarization, etc.)

---

## 6) Future Features (V2+ Roadmap — Brief)

### 6.1 Advanced Events
- Automatic certificate generation and distribution
- Post-event feedback surveys + analytics
- Multi-session workshops tracking (tracks + prerequisites)
- Event “impact reports” (attendance trends, engagement)

### 6.2 PR Growth & Outreach
- Newsletter campaigns with audience segmentation
- Sponsor/Partner pipeline (leads → meetings → deals → deliverables)
- Public “Impact” page (yearly report and achievements)

### 6.3 Media Production Workflow
- Coverage request workflow (committee request → media tasks → approvals)
- Content calendar (planning posts, deadlines, assignments)
- Asset library (brand kit, templates)

### 6.4 Chat & Collaboration (Optional)
- Committee chat channels synced with memberships
- Announcement channel (read-only)
- Moderation and safety tools

### 6.5 AI Assistance (Optional)
- Knowledge base search for policies/resources
- Event recommendations based on interests
- Draft event recap assistance for media (human-reviewed)

### 6.6 Better Admin & Analytics
- More detailed dashboards:
  - member activity
  - committee contribution metrics
  - recruitment funnel metrics
- Export center with approvals and logs

---

## 7) Success Metrics for V1 (How we measure value)
- Portal successfully used for at least one full recruitment cycle
- Portal used to support at least one major event check-in flow
- Committees actively use tasks/resources instead of scattered tools
- Public site becomes the official reference for events and committees

---

## 8) Summary
V1 will deliver a complete, secure portal that covers:
- Public presence
- Member operations
- Committee workspaces
- Event operations
- HR recruitment pipeline
- Basic PR/media publishing
with governance and auditability for leadership.
